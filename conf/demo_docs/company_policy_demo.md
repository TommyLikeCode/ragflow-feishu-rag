# 公司公共制度 / IT 支持 / 办公入口

本示例文档用于公司公共知识库演示，适合被归类为 public 级别知识。

## 公司统一办公入口

公司统一办公入口是飞书。员工日常的通知、审批、工单、知识问答与协作入口都尽量统一在飞书中完成。

## IT 工单提交方式

IT 支持工单可以通过飞书审批或公司工单系统提交。提交时请尽量补充问题描述、设备信息、发生时间与截图。

## VPN 申请要求

VPN 申请需要填写以下信息：

- 使用用途
- 所属部门
- 直属负责人
- 预计使用期限

若涉及外部网络访问，请在申请中说明具体业务场景与安全原因。

## 常见问题

常见咨询包括账号权限、网络访问、设备报修、打印机故障、会议设备支持等。
