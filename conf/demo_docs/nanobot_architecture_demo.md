# Nanobot 企业级多渠道 Agent 平台架构

本示例文档用于技术部知识库演示，描述 Nanobot 的企业级多渠道 Agent 平台能力。

## 平台定位

Nanobot 是企业级多渠道 AI Agent 平台，面向企业办公场景提供统一的智能入口。

## 支持入口

Nanobot 支持飞书、Discord、Telegram、WhatsApp 等入口，可按企业实际需求接入不同协作平台。

## 大模型路由

Nanobot 基于 LiteLLM 做大模型路由，能够在不同模型之间进行统一调度与切换。

## 核心能力

- 工具调用
- 插件系统
- RAG 检索增强问答
- 事件驱动处理
- 异步任务执行

## 架构特点

Nanobot 适合企业 Agent 场景，原因是它同时兼顾了多入口接入、任务编排、工具扩展与检索能力。
